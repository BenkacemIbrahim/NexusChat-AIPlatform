## Project Title

AI Chat Platform (Laravel + Next.js)

## One-Paragraph Description

Built a full-stack AI chat platform with a Laravel 11 API and Next.js 15 frontend. The system supports secure user authentication, persistent conversation history, and AI responses through Groq. The repository is production-style with CI, lint/type/build checks, architecture and API documentation, and a contributor-ready structure for team collaboration.

## Key Technical Wins

- Implemented token-based auth and protected API routes with Laravel Sanctum.
- Designed persistent message storage and paginated history retrieval.
- Integrated external LLM inference with error-safe handling and structured failures.
- Delivered a complete frontend product surface: auth, dashboard, chat, docs, legal, and marketing pages.
- Added CI workflow plus repo standards (`CONTRIBUTING`, `SECURITY`, `CODE_OF_CONDUCT`, changelog).

## Tech Stack

- Backend: PHP, Laravel 11, Sanctum, MySQL
- Frontend: Next.js 15, TypeScript, Tailwind CSS
- Tooling: ESLint, TypeScript, GitHub Actions CI
- AI Provider: Groq API
